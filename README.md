# AutoHotkey2
Scripts' AutoHotkey2

## Описание скриптов

Этот репозиторий содержит два AutoHotkey (v2) скрипта для удобной работы с текстом и раскладками клавиатуры.

### 1. `GE_and_UKR_keyboard.ahk`
Позволяет быстро вводить специфические немецкие и украинские символы без добавления и переключения полноценных языковых раскладок в Windows.

*   **Немецкие символы (Правый Alt):**
    *   `Right Alt` + `a / o / u / s` ➔ **ä, ö, ü, ß**
    *   `Right Alt` + `Left Ctrl` + `a / o / u` ➔ **Ä, Ö, Ü**
*   **Украинские символы (Левый Alt):**
    *   `Left Alt` + `s / ] / ' / u` ➔ **і, ї, є, ґ**
    *   `Left Alt` + `Left Ctrl` + `s / ] / ' / u` ➔ **І, Ї, Є, Ґ**

### 2. `swap_language.ahk`
Инструмент для быстрого исправления текста, набранного по ошибке в неправильной раскладке (например, `ghbdtn` ➔ `привет` или наоборот). Работает аналогично Punto Switcher, но только по вашему запросу.

*   **Как использовать:** Выделите неправильно набранный текст и нажмите **боковую кнопку мыши (Назад / XButton1)**.
*   **Особенности работы:**
    *   Переводит английскую QWERTY-раскладку в русскую ЙЦУКЕН (и обратно).
    *   Корректно обрабатывает регистр букв и спецсимволы.
    *   Безопасно использует буфер обмена: ваше предыдущее содержимое буфера (картинки, файлы, другой текст) автоматически восстанавливается после замены текста.
